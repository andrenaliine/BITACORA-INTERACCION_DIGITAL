# Clase de leds  
Conocer entorno https://kno.wled.ge/  
Materiales:  
- Esp32  
- Resistencia 330k  
- Tira led ws2812  
***Conectar LED a ESP32 en nuestra placa:***  
GND LED -> GND ESP32  
DIN LED -> 5V ESP32  
PIN 13 ESP32 -> Resistencia 330k -> DIN LED

Dirigirse a: https://install.wled.me/ y realizar el instalado del soporte, conexión USB con la placa, levantar conexión wifi desde nuestro dispositivo móvil a pc y luego conexión a esa misma red a esp32 en la misma página. por ultimo comunicar el puerto de salida (en este caso PIN 13 de ESP32) en configuraciones y listo!! ahora puedes controlar el color de las leds.
