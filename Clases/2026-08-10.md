# ¿Cómo funciona el chip 555?

El chip 555 tiene 8 terminales:

* **1. GND:** Terminal de alimentación, se conecta a tierra del circuito, se conecta a negativo.
* **2. Trigger:** Hace que se active o no la señal de salida en la patita 3.
* **3. Salida (output):** Aquí se recoge nuestro tren de pulsos.
  * Se puede conectar un LED para confirmar si el pulso se está dando.
* **4. Reset:** Usualmente se conecta a la alimentación positiva en caso de que no se use.
* **5. Control de voltaje:** Se pone algún condensador a tierra para almacenar la energía y que no pase de golpe.
* **6. Threshold:** Entrada a un comparador interno que tiene el chip. Se utiliza para poner la patita nivel bajo.
* **7. Discharge:** Descarga el condensador externo.
* **8. VCC:** Se conecta a positivo y es la alimentación.
